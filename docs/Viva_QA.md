# Viva / Interview Questions

### 1. What is the purpose of this project?
It manages hotel rooms and reservations through a console-based Java application.

### 2. Why did you use ArrayList?
It provides a dynamic collection for storing room and reservation objects.

### 3. What is encapsulation?
Keeping data private inside a class and accessing it through controlled methods.

### 4. How is double booking prevented?
A room has a booked status, and a reservation is allowed only when that status is false.

### 5. How is the bill calculated?
Total amount = price per night × number of nights.

### 6. What happens when a reservation is cancelled?
The reservation is removed and its room becomes available again.

### 7. How is input validated?
The program checks empty input, phone format, numeric ranges, room existence, and availability.

### 8. What would you add to a real-world version?
A database, login/authentication, date-based availability, payments, and a web or graphical interface.
