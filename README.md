# Hotel Reservation System — Internship Project

## Overview
A console-based Java application for managing hotel rooms and customer reservations.

## Features
- View available rooms
- Make reservations
- Calculate room charges
- View and search reservations
- Cancel reservations
- View hotel statistics
- Input validation

## Technologies
Java, OOP, ArrayList, Scanner, Console I/O

## Run Online
Open an online Java compiler such as OnlineGDB, paste `src/HotelReservationSystem.java`, and click Run.

## Run Locally
```text
javac src/HotelReservationSystem.java
java -cp src HotelReservationSystem
```

## Suggested Demo
View rooms → book room 301 for 2 nights → view reservation → search RES1001 → view statistics → cancel RES1001.
